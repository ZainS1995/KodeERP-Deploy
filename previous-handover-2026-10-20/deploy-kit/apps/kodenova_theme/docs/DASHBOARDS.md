## Sandbox import without migrate
`bench --site kodeerp.localhost execute kodenova_theme.dashboards.import_now` imports exactly these files
the way migrate would and sets `User.default_workspace = "KodeERP Home"` for desk users without one.

## Currency / company rules
- Every figure is scoped to one company: explicit filter > user default > first company the user may read
  (`api.dashboard._company`). Nothing is summed across companies.
- Money cards return a string formatted with the company's currency and number system
  (lakh/crore for PK/IN/BD/NP/LK, K/M/B elsewhere) because Frappe's number card would otherwise use
  the site currency. Charts show plain numbers (no symbol) for the same reason.
- List cards use `base_*` (company-currency) fields, so they stay correct even if an invoice is in a
  foreign transaction currency.

## Translations
All strings: `/workspace/kodeerp/docs/dashboard-strings.txt`. JS uses `__()`, Python `_()`, the HTML
blocks translate every `[data-i18n]` node with `__()` at render.

## Rollback
`git revert` the commit, then on the site delete: Custom Workspace (Accounting, Selling, Buying, Stock),
Workspace "KodeERP Home", Sidebar "KodeERP", Number Cards / Dashboard Charts / Chart Sources with
module "Kodenova Theme", Custom HTML Blocks "KodeERP Greeting"/"KodeERP Quick Actions", and clear
`User.default_workspace`. Deleting the Custom Workspace rows restores the stock ERPNext layouts.
